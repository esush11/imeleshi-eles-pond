# ele's pond

Little magic things I vibe-coded, live at the Netlify site connected to this repo.

- `index.html`: the koi pond hub, one lily pad per project
- one folder per project: `index.html` is the project page (preview, how to play, prompt, bugs), plus the app files
- `_tools/`: the script and prompts used to generate the project pages

Every commit to `main` redeploys the site automatically.
